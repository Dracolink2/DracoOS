# DracoOS
DracoOS est un OS simulé fait en python ( mais avec des versions .exe bien sûr ), il est fait pour être rapide et moddable facilement.
Il est fait pour évoluer rapidement grâce à ce dépôt.
Ce dépôt vas donc servir pour télécharger dracoOS, mais aussi pour télécharger ces apps (soit via le dépôt sur GitHub , soit direct via DracoOS)

J'aime bien travailler sur ce projet , autant que sur La Plaine, mais ce projet me tient à cœur car il est le deuxième projet qui as survécus jusqu'à maintenant !!!
Merci beaucoup pour les personnes qui téléchargent cet OS .
Attention : cette OS simulé seras mis à jour souvent, il seras quasiment impossible de récupérer les anciennes versions ( sauf si, bien sûr, y'a un grand changement de version, par exemple : DracoOS V0.9.9 à DracoOS V1 , il existeras donc un dépôt avec DracoOS V0.9 et un avec dracoOS V1)
